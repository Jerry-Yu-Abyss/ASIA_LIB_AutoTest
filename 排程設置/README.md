# 自動排程設置

安裝好環境後，雙擊專案根目錄的 `啟動檢測.pyw`，在「自動排程」區操作：

1. 選擇每日或每週，輸入執行時間（24 小時制；多個時間用逗號分隔，例如 `09:00, 18:30`）。每週排程還需勾選星期。
2. 在視窗上方選擇檢測項目、LINE 回報方式與是否顯示瀏覽器。
3. 按「儲存／更新排程」。修改選項後也要再按一次，才會更新 Windows 工作排程。

按「移除排程」可刪除本專案建立的工作。工作名稱是 `AU Library Automated Test`，可在 Windows 工作排程器查看。測試報告保存在專案的 `.local/reports/`。

排程按電腦的本地時間執行；請確認時區、電腦開機狀態，以及設定排程的使用者已登入。若前一次檢測尚未結束，新一次不會重疊執行。排程設定另存於 `config/排程.local.json`，但換電腦後仍需在新電腦重新按「儲存／更新排程」。

實際建立、讀取與移除 Windows 工作排程的程式是 [`schedule_tasks.py`](schedule_tasks.py)；此檔由檢測視窗呼叫，不需要單獨執行。
