# 個人化書單分類號抓取

把亞洲大學圖書館個人化書單匯出的 `.xls` 或 `.xlsx` 放進 [`待處理`](./待處理) 資料夾。程式依每筆書目網址開啟書目頁，擷取「索書號(卷期)」開頭的分類號，並在 [`完成`](./完成) 產生同日期檔名的 `.xlsx`。

輸出欄位依範例保留：`書目資訊`、`在架/館藏量`、`分類號`、`URL`。直接從網站抓取時，在架/館藏量由書目頁的館藏列計算。索書號若以 `DVD` 等館藏類型開頭，程式會擷取後面的分類號。同一本書若有多個不同分類號，會以 `、` 分隔，並產生 `_待核對.csv`。無法取得分類號時保留空白，原因也記在待核對清單。來源檔不會被覆寫。

## 安裝

在專案根目錄執行：

```powershell
py -m pip install selenium webdriver-manager requests lxml openpyxl
```

## 處理匯出檔

```powershell
py ".\個人化書單分類號抓取\抓取分類號.py"
```

程式會選擇 `待處理` 中最新的檔案。也可指定檔案：

```powershell
py ".\個人化書單分類號抓取\抓取分類號.py" --input "C:\路徑\彥丞1151005.xls"
```

網站匯出的舊式 `.xls` 若是 Excel 網頁格式，請連同它引用的 `.files` 資料夾一起放進 `待處理`。若只有單一真正的二進位 `.xls`，先用 Excel 另存成 `.xlsx`。

## 直接從網站讀取

```powershell
py ".\個人化書單分類號抓取\抓取分類號.py" --live
```

程式會開啟 Chrome。請自行登入圖書館網站，再回到終端機按 Enter。程式會進入「我的書房 → 個人化書單」，只讀取該列表的書目與總筆數；若讀到的筆數與頁面總筆數不同，就停止並報錯。程式不讀取或儲存帳號密碼；登入階段由你操作。若網站版面改變導致找不到書目連結，使用上方的匯出檔模式即可。
