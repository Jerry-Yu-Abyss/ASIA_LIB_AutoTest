# 個人化書單分類號抓取

執行程式後會開啟 Chrome 和圖書館登入視窗。你完成登入後，程式自行進入「我的書房 → 個人化書單」，依每筆書目網址取得「索書號(卷期)」的分類號，並在 [`完成`](./完成) 產生當日檔名的 `.xlsx`。

輸出欄位依範例保留：`書目資訊`、`在架/館藏量`、`分類號`、`URL`。在架/館藏量優先取自書單列表，列表沒有數值時才由書目頁的館藏列計算。索書號若以 `DVD` 等館藏類型開頭，程式會擷取後面的分類號。同一本書若有多個不同分類號，會以 `、` 分隔，並產生 `_待核對.csv`。無法取得分類號時保留空白，原因也記在待核對清單。來源檔不會被覆寫。

## 安裝

在專案根目錄執行：

```powershell
py -m pip install selenium webdriver-manager requests lxml openpyxl
```

## 直接登入並抓取

```powershell
py ".\個人化書單分類號抓取\抓取分類號.py"
```

程式開啟登入視窗後，請在 Chrome 自行輸入帳密；登入成功會自動開始，不必回終端機按 Enter。程式不讀取或儲存帳號密碼。它只讀「個人化書單」列表，並核對頁面顯示的總筆數；筆數不一致時會停止。

## 處理匯出檔

也可以把網站匯出的 `.xls` 或 `.xlsx` 放進 [`待處理`](./待處理)，再指定檔案：

```powershell
py ".\個人化書單分類號抓取\抓取分類號.py" --input "C:\路徑\彥丞1151005.xls"
```

網站匯出的舊式 `.xls` 若是 Excel 網頁格式，請連同它引用的 `.files` 資料夾一起放進 `待處理`。若只有單一真正的二進位 `.xls`，先用 Excel 另存成 `.xlsx`。
